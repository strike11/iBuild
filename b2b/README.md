# iBuild B2B

Admin app for platform operators and residential-complex managers — projects, units, leads, media, and moderation.

Built with Flutter. Supports **English, Russian, and Uzbek**.

See the [root README](../README.md) for an overview of the iBuild platform.

```bash
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:4000/v1
```
